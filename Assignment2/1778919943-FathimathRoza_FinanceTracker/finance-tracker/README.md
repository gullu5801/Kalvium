# Personal Finance Tracker

## Selected Problem Statement
Option 5 – Personal Finance Tracker

## Description
A React-based web application used to track income and expenses dynamically.

## Features Implemented
- Add transactions
- Delete transactions
- Filter income/expense
- Dynamic balance calculation
- Local storage support
- Responsive UI

## Technologies Used
- React JS
- Vite
- Tailwind CSS

## Steps to Run
1. npm install
2. npm run dev

## Additional Notes
Frontend-only application using React Hooks.
