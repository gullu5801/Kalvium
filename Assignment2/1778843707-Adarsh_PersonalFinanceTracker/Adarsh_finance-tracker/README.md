# Finance Tracker

A React-based finance tracking application built with Vite.

## Features

- Track income and expenses
- Visualize spending with charts
- Filter transactions
- View account balance

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

## Project Structure

- `src/` - React components and pages
- `src/components/` - Reusable UI components
- `src/pages/` - Page components
- `src/data/` - Mock data
- `public/` - Static assets
