# Travel Planner

## Problem Statement
Build a React Mini Web Application with multiple pages, trip management, itinerary tracking, and task completion.

## Features
- Add new trips
- Delete trips
- View trip details
- Manage itinerary/tasks
- Mark tasks as completed
- Local storage support
- Multiple pages using React Router

## Technologies Used
- React
- Vite
- React Router DOM
- CSS
