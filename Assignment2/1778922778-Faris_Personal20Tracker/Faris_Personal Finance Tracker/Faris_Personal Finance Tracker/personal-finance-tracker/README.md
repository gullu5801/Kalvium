# Personal Finance Tracker

## Selected Problem Statement
Personal Finance Tracker

## Description
A React application to track income and expenses.

## Features
- Add transactions
- Income/Expense filter
- Balance summary
- Local storage support
- React Router navigation

## Technologies Used
- React
- Vite
- React Router DOM
- CSS

## Steps to Run

```bash
npm install
npm run dev
```

## Additional Notes
Frontend-only application using React Hooks.
