# Smart Expense Tracker

## Selected Problem Statement
Personal Finance Tracker

## Description
Smart Expense Tracker is a React-based web application used to manage income and expenses. Users can add transactions, filter them, and visualize financial data using charts.

## Features Implemented
- Dashboard with balance summary
- Add income and expense transactions
- Filter transactions
- Transaction list
- Pie chart visualization
- Responsive design

## Technologies Used
- React JS
- CSS
- Recharts

## Steps to Run
1. Install dependencies:
npm install

2. Start the project:
npm run dev

## Additional Notes
- Frontend only project
- Uses React Hooks
- Responsive UI
