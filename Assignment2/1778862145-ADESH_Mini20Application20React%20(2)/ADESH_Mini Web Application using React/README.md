# Travel Planner App

## Selected Problem Statement
Option 6 – Travel Planner

## Description
Travel Planner is a React web application used to manage trips and travel itineraries. Users can add trips, view trip details, add tasks, and mark tasks as completed.

## Features Implemented
- Add Trip
- View Trips
- Trip Details Page
- Add Tasks
- Mark Tasks Completed
- Responsive UI
- React Router Navigation
- Local Storage

## Technologies Used
- React
- Vite
- CSS
- React Router DOM

## React Hooks Used
- useState
- useEffect

## Steps to Run the Project

1. Install dependencies

npm install

2. Start the project

npm run dev

3. Open browser

http://localhost:5173

## Additional Notes / Assumptions
- Frontend-only project
- No backend/database used
- Local storage used for saving trip data
- Responsive design implemented
