
# Smart Expense Tracker

## Description
This is a simple web-based application that allows users to add, manage, and track their daily expenses. It dynamically updates the UI and calculates the total expense.

## Features
- Add expenses (name and amount)
- Delete expenses
- Real-time total calculation
- Dynamic UI updates without page reload

## JavaScript Concepts Used
- ES6 (let, const, arrow functions)
- Template literals
- Destructuring
- Spread operator
- Pure functions
- Higher-order functions
- Array methods (map, filter, reduce)
- Recursion
- Object-Oriented Programming (class)
- Prototypal inheritance
- IIFE

## Recursion Explanation
Recursion is used in the recursiveTotal function to calculate the sum of all expenses.

## OOP & Prototypal Inheritance
OOP is implemented using the Expense class. Prototypal inheritance is demonstrated using SpecialExpense.

## How to Run
Open index.html in any browser.
