# Expense Tracker

## Description
A mini web application to manage daily expenses using HTML, CSS, and JavaScript.

## Features
- Add expenses
- Delete expenses
- Filter by category
- Calculate total expense

## JavaScript Concepts Used
- ES6
- Arrow Functions
- Template Literals
- Destructuring
- Spread Operator
- map(), filter(), reduce()
- Pure Function
- Higher-Order Function
- Recursion
- OOP
- Prototype Inheritance

## How to Run
1. Open index.html
2. Add expenses
3. View total and filtered results
