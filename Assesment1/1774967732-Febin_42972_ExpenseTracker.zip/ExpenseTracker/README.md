# 💰 Smart Expense Tracker

## 📌 Project Description
The Smart Expense Tracker is a browser-based mini web application that allows users to add, manage, and track their expenses dynamically. It calculates the total expenses and displays them in real-time without reloading the page.

---

## 🚀 Features
- Add new expenses (title, amount, category)
- View all expenses dynamically
- Delete expenses
- Automatic total calculation
- Clean and responsive UI

---

## 🧠 JavaScript Concepts Used

### ✅ ES6 Features
- let, const
- Arrow functions
- Template literals
- Destructuring
- Spread operator

### ✅ Functional Programming
- Pure functions (`calculateTotal`)
- Higher-order functions (`filter`, `reduce`)

### ✅ Recursion
- Implemented in `recursiveTotal()` function to calculate total recursively

### ✅ Object-Oriented Programming (OOP)
- `Expense` class used to create expense objects

### ✅ Prototypal Inheritance
- JavaScript uses prototype-based inheritance internally with classes

### ✅ IIFE
- Used to initialize the application

---

## 🔁 Where Recursion is Used
The `recursiveTotal()` function calculates the total expense using recursion instead of loops.

---

## 🧱 OOP & Prototype Usage
- `Expense` class is used to create structured expense objects
- Demonstrates object creation and reuse
