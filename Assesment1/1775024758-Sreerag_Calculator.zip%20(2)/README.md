# Smart Calculator

## Project Description

This is a simple and clean Smart Calculator built using HTML, CSS, and JavaScript. It performs basic arithmetic operations and provides a user-friendly interface.

---

## Features

* Addition, Subtraction, Multiplication, Division
* Percentage calculation
* Clear (C) button to reset input
* Delete (⌫) button to remove last digit
* Decimal number support
* Error handling for invalid expressions
* Responsive and modern UI

---

## Technologies Used

* HTML (Structure)
* CSS (Styling)
* JavaScript (Functionality)

---

## How to Run the Project

1. Download or clone the project folder
2. Open the folder in your code editor (VS Code recommended)
3. Open `index.html` in any web browser

---

## How It Works

* The user clicks buttons to input numbers and operators
* JavaScript stores the input in a variable
* When "=" is pressed, the expression is evaluated
* The result is displayed on the screen

---
