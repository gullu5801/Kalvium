# 💰 Expense Tracker

A simple web application to track daily expenses using HTML, CSS, and JavaScript.

---

## 🚀 Features

- Add expenses
- Delete expenses
- View total amount
- Dynamic UI updates

---

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript (ES6)

---

## 📚 Concepts Used

- OOP (Class)
- Array methods (map, filter, reduce)
- DOM Manipulation
- Recursion
- IIFE (Immediately Invoked Function)

---

## ▶️ How to Run

1. Open the project folder
2. Open `index.html` in browser
3. Add expenses and track total
