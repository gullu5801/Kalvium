Project Title

Smart Expense Manager

Description

Smart Expense Manager is a browser-based mini web application built using HTML, CSS, and JavaScript (ES6). It allows users to add, delete, and manage expenses dynamically while calculating totals and applying recursive tax calculation.

JavaScript Concepts Implemented
ES6 (let, const, arrow functions)
Template literals
Destructuring
Spread operator
Pure function (calculateTotal)
Higher-order function (processExpenses)
Recursion (calculateTaxRecursive)
Object-Oriented Programming (Utility & Expense class)
Prototypal inheritance (Expense extends Utility)
IIFE (to avoid global pollution)
Array methods (forEach, filter, reduce)
Recursion Explanation

The function calculateTaxRecursive() applies 2% tax repeatedly using recursion until the base condition is met.

OOP & Prototypal Inheritance

The Expense class extends the Utility class using JavaScript class inheritance, demonstrating prototypal inheritance.
