# Smart Expense Tracker

## Description
A mini web application to manage and calculate expenses dynamically.

## JavaScript Concepts Used

- ES6 (let, const, arrow functions)
- Template Literals
- Destructuring
- Spread Operator
- Pure Functions
- First-Class Functions
- Higher-Order Functions
- Recursion
- OOP (Class)
- Prototypal Inheritance
- IIFE
- map(), filter(), reduce()

## Recursion
Used in recursiveSum() to calculate total expenses.

## OOP
Expense class created using ES6 class syntax.

## Prototypal Inheritance
PremiumExpense inherits from Expense.
